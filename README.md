# 🛍️ Retail Sales Analysis using PostgreSQL

## 📌 Project Overview

This project focuses on analyzing retail sales data using **PostgreSQL** to explore sales performance, customer purchasing behavior, product categories, and transaction trends.

The goal is to transform raw retail transaction data into meaningful business insights using SQL queries and data analysis techniques.

Through this project, I practiced writing SQL queries to answer practical business questions, summarize sales data, and identify patterns that can support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall retail sales and transaction data.
- Identify the number of unique customers and product categories.
- Calculate total sales and average customer age.
- Compare sales performance across product categories and genders.
- Analyze monthly sales trends.
- Identify high-value transactions and customer spending patterns.
- Classify transactions into different time-of-day shifts.

## 🛠️ Tools & Technologies

- **Database:** PostgreSQL
- **SQL Editor:** pgAdmin 4
- **Language:** SQL
- **Dataset Format:** CSV

## 💻 Sample SQL Queries

### 1. Total Sales and Number of Transactions by Category

```sql
SELECT
    category,
    SUM(total_sale) AS net_sales,
    COUNT(*) AS total_orders
FROM retail_sales
GROUP BY category
ORDER BY net_sales DESC;
```

### 2. Unique Customer Count

```sql
SELECT
    COUNT(DISTINCT customer_id) AS unique_customers
FROM retail_sales;
```

### 3. Average Customer Age for Beauty Purchases

```sql
SELECT
    AVG(age) AS average_age
FROM retail_sales
WHERE category = 'Beauty';
```

### 4. Monthly Average Sales Analysis

```sql
SELECT
    EXTRACT(YEAR FROM sale_date) AS year,
    EXTRACT(MONTH FROM sale_date) AS month,
    AVG(total_sale) AS average_sales
FROM retail_sales
GROUP BY 1, 2
ORDER BY 1, 2;
```

### 5. Classifying Transactions by Time of Day

```sql
SELECT
    *,
    CASE
        WHEN EXTRACT(HOUR FROM sale_time) < 12
            THEN 'Morning'
        WHEN EXTRACT(HOUR FROM sale_time) BETWEEN 12 AND 17
            THEN 'Afternoon'
        ELSE 'Evening'
    END AS shift
FROM retail_sales;
```
